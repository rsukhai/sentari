# Журнал автономності — Лабораторна 3

Рівні довіри — ті самі, що в Лаб. 1–2 ([`../lab1/autonomy-log.md`](../lab1/autonomy-log.md), [`../lab2/autonomy-log.md`](../lab2/autonomy-log.md)): **L0** — читання; **L1** — агент пропонує, кожну зміну приймаю вручну; **L2** — файли без питань, команди лише з дозволу. Автономні прогони харнеса йдуть у режимі `dontAsk` з явним переліком інструментів (див. [`factory.md`](factory.md)); обходу дозволів (`bypassPermissions`, `--dangerously-skip-permissions`) немає ні в сесіях, ні в коді харнеса.

Межа з Лабораторною 2 — стан `origin/main` на момент початку (`071ac814`: злито кроки 00–05); кроки 06–10 Лаб. 2 лежать у гілці `lab2/10-package` і чекають злиття.

## Мова артефактів

Документація, журнали й коментарі в коді — **українською**; промпти задач у черзі (`tasks.jsonl`) — українською, бо задачі описують український репозиторій; тексти для моделей, що йдуть у кожен запит (системний промпт асистента), лишаються англійською, як у Лаб. 2. Вартість українського тексту в токенах виміряно в Лаб. 1 ([`../lab1/cost.md`](../lab1/cost.md), розділ 3).

# Впевнені помилки — Лабораторна 1

Контракт: `src/health.ts` (Zod-схема `HealthResponse`), `tests/health.test.ts` —
закомічено червоним у `main` (`a9b2a822`) до того, як задачу отримав будь-який
агент. Задача: `Додай ендпоінт GET /api/health...` — однаковий запит для обох
інструментів, у режимі плану, кожен у своїй гілці.

*Примітка щодо формату*: hook-журнал фіксує лише **виклики інструментів** (шлях/команда), не текст міркувань агента. Тому «план» тут відновлено з фактичних дій у журналі й із фінального diff, а не процитований дослівно.

## Наслідок для налаштувань

Після інциденту #1 додано `.codex/hooks.json` → `PreToolUse` (`scripts/agent-env-guard.mjs`), що сканує текст будь-якої `Bash`/`exec_command`/`apply_patch` команди на згадку `.env`/`.env.local`. Перевірено емпірично: та сама команда з помилки #1, пропущена через оновлений guard, повертає `permissionDecision: "deny"` (exit code 2).

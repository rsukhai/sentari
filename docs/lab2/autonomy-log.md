## Порядок «специфікація → реалізація»

```bash
git log --diff-filter=A --format='%h %ad %s' --date=iso -- docs/lab2/spec.md
# e42c784e 2026-10-31 … docs(lab2): специфікація v1
git log --format='%h %s' 8c640b6c..HEAD -- src scripts tests app
# (порожньо на момент коміту специфікації — реалізації Лаб. 2 ще не було)
```

Перевірка журналу: у `.agent-log/claude-code.jsonl` усі 5 записів, що згадують
`docs/lab2/spec.md`, — `Read` (3) і `Bash` (2: `ls`/`wc`, `git log`). Жодного
`Write`/`Edit` агента у файл специфікації.

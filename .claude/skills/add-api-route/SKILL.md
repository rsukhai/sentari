# Додати API-маршрут

Назва маршруту `<name>` — малі латинські літери, цифри, дефіси (напр. `health`).

## Кроки

1. Спершу контракт: `src/<name>.ts` зі zod-схемою відповіді. Тип виводь через `z.infer`, не пиши вручну.
2. Потім тест: `tests/<name>.test.ts` імпортує обробник відносним шляхом `../app/api/<name>/route` і перевіряє статус та відповідність схемі. Тест не ходить у мережу.
3. Лише тоді обробник: `app/api/<name>/route.ts` експортує функцію HTTP-методу (`GET`, `POST`, …) і відповідає через `Response.json(...)`. Схему імпортуй відносно (`../../../src/<name>`), не через аліас `@/`: Vitest його не знає, `npm test` впаде, хоча `typecheck` пройде.
4. Запусти `npm test` і `npm run typecheck`.
5. З кореня репозиторію: `node .claude/skills/add-api-route/scripts/check-route.mjs <name>`.
6. Не звітуй «готово», поки скрипт не поверне 0 і `npm test` не зелений. Якщо скрипт повернув 1 — виправ рядки `FAIL` і запусти знову.

## Межі

- `.env*` і `package.json` не чіпай: залежності додає людина.
- Загальні правила — в `AGENTS.md`; тут лише ця процедура.
